# 油运行业研究

## 核心认知（先记住这三句，其余都是展开）

1. **油运的核心变量不是油价，是"吨海里需求 ÷ 有效运力"。** 油价只在两条路上影响油运：价差套利决定货流方向（Brent-WTI、东西套利），contango 决定要不要用 VLCC 当浮仓。价格本身涨跌对运价是二阶的。
2. **距离比量更重要。** 同样一吨油运距拉长 30%，等效于需求增加 30%。历史参照：2025 年全球原油海运贸易量仅 +0.8%，但吨海里需求 +3.6%。
3. **总运力 ≠ 有效运力。** 需扣除：受制裁/影子船队、15 年以上被大货主拒收的老船、STS 过驳与等待、绕行与低速航行。本轮周期的全部秘密都在这个缺口里。

> ### ⚠ 使用边界（第八轮回测得出，动手前必读）
> **这套框架是「行业状态仪表盘」，不是「买卖信号发生器」。**
> - **能可靠回答**：处于周期什么位置、景气是真是假、运价大致会回到哪里、谁在真赚钱。
> - **回答不了**：什么时候该买卖。
> - **最关键的一条**：**FFA／期租能极准地预测运价（2019 年误差 <10%），但不能用它推断股价**——2019-10 现货/FFA gap 3.69 倍、运价随后暴跌 75%，**股价却涨了 77%**，因为回落后（7.5–8 万）仍是当时中枢（2.13 万）的 3.5 倍，盈利仍在上修。
> - **已被历史证伪、禁止作为方向性判断依据的三个信号**：① 运价创极值 = 见顶；② FFA gap = 风险；③ 多数字同区间 = 共识中枢。
> - **真正的股价风险变量是 PB 的绝对水平**（2019 年 0.88 vs 当前 2.23–2.88，差 2.5–3 倍）。
> 详见 `references/pitfalls.md` 第九节。

## 交付物形态：仪表盘，不是研报

**默认产出 `assets/dashboard-template.html` 那样的「状态仪表盘」，而不是长篇论证式研报。**

结构与必备元素：
1. **顶部定位声明**（橙色横幅）：明确"这是仪表盘不是信号机"，列出已证伪的三项
2. **核心状态灯**：5 格，红/橙/绿/蓝状态色 + 所属层级标签（运价／供给／预期／定价／筹码）
3. **五维框架状态矩阵**：维度｜核心指标｜当前值｜**对照基准**｜状态｜读数说明
4. **四层传导链读数**：供需→运价→盈利→定价，每层给关键读数与解读
5. **【v2 必带】标的映射层**：标的｜VLCC 艘数｜现货/期租敞口｜TCE 弹性｜H1 业绩｜结构特征。
   **没有这一层，行业读数无法翻译成个股**——「景气真实」回答不了「谁赚多少」
6. **仪表与阶梯图**：景气度仪表 + 价格阶梯（现货→预期→常态）+ 可算的门槛图（如浮舱套利）
7. **【v2 必带】数据保质期表**：指标｜频率｜时点｜**状态（有效／滞后／已过期）**｜失效判据
8. **可信度与待核清单**：每个数字标注「一手／转引／待核／推导」
9. **【v2 必带】触发器与自我证伪条件**：观测触发器（何时该再看一眼）+ 自我证伪条件（我错了会先在哪里看出来）
10. **使用边界（红线区）**：❌ 禁止的三项推断 + ✅ 可可靠回答的四类问题

**硬性要求：**
- **每个数字必须带时点**——本轮运价数日内可变 +68%，日频数据过期即废
- **必须有「对照基准」列**——没有基准的数值无法判断高低
- **「转引」「一手」「推导」必须区分标注**——同源头多次转引 ≠ 独立验证；自行推导 ≠ 已证实
- **先查保质期表，再决定能否引用**
- **指数知名度 ≠ 可用性**：先用前必须确认该航线/指标**是否有真实成交**（TD3C 失真教训，见 pitfalls 第十节）
- **极值运价 ≠ 公司实现值**：中间隔四层——航线有无成交／本公司是否参与／现货敞口／传导滞后（约 1 季度）
- 配色遵循**涨红跌绿**（中国习惯）；仪表盘为**浅底深字**
- 交付前跑 `scripts/check_report.py`

## 五维运价框架（行业通行口径）

| 维度 | 性质 | 核心指标 |
|---|---|---|
| 原油需求 | 长期方向 | 海运量、**吨海里**、OPEC+ 产量、进口国结构 |
| 有效运力 | 弹性高度与持续性 | 船队规模、订单/运力比、交付排期、拆解量、船龄、制裁运力 |
| 运距 | **乘数效应** | 绕行比例、运河通行量、贸易流重构（俄油东移、美油出口） |
| 地缘政治 | **提前布局信号** | 海峡通行量、STS 等待天数、战争险费率。**注意：一旦对原油供给形成大幅冲击，利好效应可能反转** |
| 浮舱囤油 | **景气放大器** | contango 深度、VLCC 浮舱艘数、商业库存与 SPR 补库节奏 |

前三维是基本面；地缘是信号（且可能反转）；浮舱是油运独有的放大器——contango 下租 VLCC 当浮仓会**直接抽走现货运力**，形成"需求↑→运力↓→运价↑"的正反馈。

## 四层传导链与取数顺序

严格按此顺序取数，前一层没落实不要跳到下一层：

**第一层 供需驱动**（最难取、最有 alpha）
船队规模/艘数/载重吨 → 在手订单与分年度交付排期 → 拆解量与船龄结构 → 制裁与影子船队规模 → 海运量与吨海里 → 绕行与通行量 → contango 与库存

**第二层 运价**
BDTI/BCTI 指数 → 分航线 TCE（**TD3C/TD15/TD22/TD34/TD6/TD7/TC1/TC7**）→ 期租成交价（1年/2-3年）→ FFA 远期曲线

**第三层 公司盈利**
分船型船队明细 → 租船结构（现货敞口 vs 长协）→ **分部收入拆解** → breakeven TCE → TCE 净利弹性 → 现金流与 capex → 分红

**第四层 定价与交易**
**PB 分位（周期股用 PB，不用 PE）** → PB vs 船队重置价值 NAV → 新造/二手/拆船三价 → 机构持仓与南向 → 筹码获利盘 → AH 溢价

完整的每层数据清单、口径、来源与可得性见 `references/data-dictionary.md`。

## 必做的六项校验（不做就不要交付）

1. **口径校验**：券商给的弹性数默认是"全船队 + 年化 + 税后"，按半年计要除以 2；"订单/运力比 37%" 是 **VLCC 单船型**口径，全油轮船队口径只有 7.8%–9.6%。**同一个指标先问清是单船型还是全船队。**
2. **TD3C 不能直接当盈利基准**：TD3C 含地缘风险溢价且霍尔木兹受阻时"有价无市"。判断公司利润要用 **波罗的海 VLCC 综合 TCE**（TD3C/TD15/TD22 加权）或公司业绩倒算的实际实现值。实测：TD3C 137 万时，TD22 只有 63.8 万，综合口径 85.6 万。
3. **多源交叉验证，但警惕"假共识"**：多个数字落在同一区间**不等于**共识，要先确认它们代表同一期限、同一主体。实测反例：1 年期租 13.51 万、卖方 2026E 隐含 13.0–13.7 万看似收敛，但 FFA Cal-27 是 33.5 万、Cal-28 只有 8.3 万、Frontline 卖船隐含 7 万——**真实分歧区间是 7–33.5 万，共识是形状（近高远低）而非水平。**
4. **报告交付前跑 `scripts/check_report.py`**：校验 HTML 标签平衡、JS 语法、ECharts 容器与 init 是否一一对应。本 skill 的四轮实战中，这个脚本抓出过 3 处 `<div class="src">` 误用 `</p>` 闭合。
5. **历史类比回测（第六轮新增，价值最高）**：交付前必须找上一轮同类驱动的完整周期做对照。油运的标准对照组是 **2019–2020**（详见 `references/pitfalls.md` 第七节）。**关键结论：运价创极值 ≠ 股价见顶**——2019-10-11 运价见顶后，中远海能真正的历史最高点是 2020-04 的 8.20，比第一波高点还高 30%；招商轮船在极值后又涨了 +77.2%、历时 3.4 个月才见顶。但一旦确认见顶，股价两个月回撤 −47.7%、运价 13 个月回撤 −98.1%。
   做法：① 定对照组 → ② 拉前复权月线 → ③ 算「滞后时长 / 期间涨幅 / 见顶后回撤」三个量 → ④ 检查有无第二波及其催化剂 → ⑤ 把历史催化剂与当前对照。
   ⚠ 局限：n 通常为 1，**历史能给出的是「回撤幅度」，不是「何时见顶」**。见顶时点由新催化剂决定，是条件命题。
6. **对自己的核查方法再核查（第七轮新增）**：纠错轮次会引入新的、更隐蔽的错误。交付前必问——① 我的"多源验证"是**真独立**还是**同一源头的多次转引**？（本次踩坑：5 个媒体全部转引同一条 Baltic 数据，独立源 = 1）；② 我在纠错时**引入的新数据**经过与初轮**同等标准**的审查了吗？（本次踩坑：用未验证换算的 FFA 60–70 万去"修正"原数，后被克拉克森口径 18.1 万证伪，差 3–4 倍）；③ 历史样本 n 多少、驱动可比吗；④ 对比口径一致吗；⑤ 有没有因为某个数"刚好能修正已知错误"就降低审查标准？
   > 元教训：**纠错是收敛的，但每一轮都会引入新错误。** 上一轮的结论，包括"自查结论"本身，都是本轮的攻击对象。

详细的踩坑清单见 `references/pitfalls.md`——**写报告前必读**，其中每一条都造成过结论错误。

## 数据源与可得性

可用工具与付费边界见 `references/data-sources.md`。要点：

- **能直接取到的**（金融数据库接口）：A/港/美股行情、财务三表、**分部收入构成**（`business_segments` 一次可取多公司多期）、估值与分位、股东与基金持仓、南向持股、现金流、分红、宏观进口。
- **必须联网搜的**：运价点位、船队订单与交付排期、breakeven、官方弹性表、船队逐船明细。**券商研报与业绩推介材料的转引优于数据库接口**——`report_search` 对"船队艘数/载重吨"类查询长期返回空。
- **付费且取不到的**：克拉克森（Clarksons）船队全口径、Kpler/Vortexa AIS 船位、波罗的海与 SSY 原始曲线。只能间接引用研报口径，**必须标注为非一手来源**。
- **判定不可信的来源**：GEP Research 一类聚合站，实测其"中国原油进口 +4.1%"与海关实际 -11.4%、"H1 拆解 47 艘"与克拉克森 24 艘直接矛盾。**遇到无一手出处的统计划，先找一个已知数做交叉检验。**

## 输出规范

- 产出 **HTML 研报**（浅底深字、ECharts 图表），不要只给文字结论。
- **每个数字必须带来源与时点**。转引数据统一标注"非一手，需核原文"。
- **主动呈现观点分歧**，不要只采信一边。例如"2028 供给墙 vs 供给真空"，专业机构是分裂的，要把两边的机构名、论据与裁决变量都写出来。
- **主动暴露自己的口径错误并修正**。如果后一轮数据推翻了前一轮结论，必须在正文与页脚显式说明，而不是悄悄改掉。
- **必须回答"运价跌到多少利润归零"**。这个问题靠 breakeven + 弹性两个数的组合，缺任何一个都无法回答。若确实取不到，要在缺口清单里标为高优先级。

## 最短验证路径（跟踪阶段）

按信号出现先后排列：

1. **波罗的海 VLCC 综合 TCE**（不是 TD3C）——判断公司能拿到的价
2. **霍尔木兹周度通行量与 STS 等待天数**——运价的直接自变量
3. **期租市场是否有新增成交**——租家不愿锁长期，比现货更早
4. **2–3 年期租成交价**——真金白银的长期预期，比 1 年期租更有信息量
5. **全球油船月度拆解量**——裁决"供给墙 vs 供给真空"
6. **季度 capex**——周期顶点加大资本开支是风险而非利好
