# 油运行业研究

先回答用户的问题，再沿“运输需求与有效供给 → 运价 → 公司盈利与现金流 → 估值”寻找决定性证据。结论可以综合，事实应分别核验。不要把旧报告的行情、参数和投资观点作为新研究默认值。

## 从问题选择研究深度

- **行业是否景气、运价为什么变**：分清原油/成品油、船型和航线，核海运量、运距、有效船日及约束变化；解释主因与相反证据。
- **哪家公司受益、是否兑现**：在行业判断上补实际经营航线、盈利船日、现货/期租/COA/POOL与权益口径，查分部利润和现金流。市场报价不能替代公司实现收益。
- **贵不贵、风险在哪里**：先建立公司盈利情景，再按资料选择正常化收益、现金流或船队NAV；PB/PE只作交叉观察。给出假设、范围和改变判断的条件。
- **旧报告是否可靠**：只复核影响当前问题的事实与推断，保留旧版本；说明哪些已支持、哪些错用、哪些仍缺证。无需把全文每个单元格重复计为独立问题。

问题明确就直接推进。范围不清但可合理推断时，说明暂定船型、区域与研究时点；缺失信息确实会改变结论时再询问。单一问题不要求完整行业报告。

## 研究主线

按任务读取 [行业研究框架](references/research-framework.md)，选择必要层次，不强制每层收集同样数量的数据。

1. **供需与机制**：全球石油需求不等于海运需求；同时看货量、运距、贸易流和区域适配。供给分在营、订单、交付、拆解及经营限制。老船、制裁和滞留可能重叠；绕航影响不要在需求和供给两侧重复计量。浮舱仅在期限、成本与可用船条件满足时讨论。
2. **运价结构**：区分指数点位、WS、航线评估TCE、期租成交/指示价、FFA与公司实现TCE。比较需统一船型、航线、日期、期间和成本定义；远期报价是合约价格，不是保证实现的预测。
3. **公司兑现**：市场航线到公司船日，再到租约收益、经营成本、折旧融资、税费及权益归属。租入船不能统一剔除；毛利、分部净利和归母不混用。分别看盈利、经营现金、债务、分派及资本开支支付/承诺。
4. **估值与情景**：区分短期高价延续、航线恢复、需求回落、交付增加等情景，说明各情景作用在哪一环。用可追溯基准建立局部测算；缺参数保留未知，不造精确目标价、概率或利润底线。

## 事实核验与综合判断

维护三种对象，避免把它们压成一个“已核实”标记：

- **事实**：一个可单独核验的指标，记录公司/船型/航线、范围、期间、单位、数值与来源定位。相同定义与版本在正文、表格和图表重复出现时共用同一事实编号。
- **计算或假设**：引用事实编号，列公式、参数、单位及适用条件；明确哪些输入尚未取得。算术通过只说明公式在声明条件下成立。
- **综合判断**：引用事实与计算，分别列支持、反证和缺失的传导环节。可以说“行业收益改善有披露支持，但公司未来利润范围未知”，不必整段一律未完成。

记录观察期、发布时间、取得时间和修订版本；旧研究时点尚未发布的材料不能用于当时判断。原文取得、指标口径匹配、复算通过与推断成立分别说明。相同上游的转载/镜像不增加独立证据；图表按船型、图例和年份定位，不用数字相近替代核验。免责声明、标题和来源标签不计为待核实数值，标签内的实际主张另拆。

## 取证和工具

本Skill能单独使用；不假定数据库、付费账号、浏览器或其他仓库已经可用。用户给的资料先定位证据；需新数据且工具可用时按 [来源与权限](references/data-sources.md)查原发布者。没有权限或原始快照时保留具体缺口，不绕过访问限制。字段含义按需查 [数据字典](references/data-dictionary.md)。

- 比较期间、FFA、敞口、PB、公司身份或反推运价时，读 [证据核对契约](references/evidence-contracts.md)，使用 `scripts/evidence_checks.py`。`blocked`保留为阻断，成功退出不等于研究通过。
- 浮舱成本、船队集合重叠、TCE增量或经验分位算术，读 [计算契约](references/calculation-contracts.md)，使用 `scripts/research_checks.py`。只计算声明参数，不联网认证输入。
- 不能用总利润除边际敏感性反推运价；需同范围基准利润、基准TCE、期间、税费、归属及局部适用区间。公司推介未披露的期间/税费保留未知。现金保本与会计保本分别解释，TCE已扣的航次成本不要重复扣减。

脚本只需Python 3.10+标准库。使用相对路径，以本Skill目录为根；另一仓库、作者缓存和历史数据文件不是运行依赖。

最短离线示例：在本Skill目录运行 `python scripts/research_checks.py --input examples/earnings-scenario.json`。这是合成情景，输出税前增量和税后机械增量，不是公司实际净利润。无需Python即可按框架分析已有文字资料；只有需要计算时才运行脚本。没有联网工具时不声称查询了最新行情。

## 交付

自然语言先给出当前可支持的答案、范围与把握程度，再说明关键证据、传导逻辑、反证、情景和最值得补的资料。没有依据时不给概率；不让免责声明替代回答，也不让措辞强度超过证据。

复杂研究可提供“事实表＋情景表＋综合判断”；简单问题用短回答。若统计完成率，分开报告待取证事实、口径冲突、待验证推断与资料说明，去重后再计数。旧台账的单元总数不是独立事实或错误数。

需要保存研究底稿时可用 [研究简报模板](assets/research-brief.md)，按问题删减字段。引用编号用于追溯，不必把内部台账全部展示给用户。

需要HTML时用 [空白仪表盘](assets/dashboard-template.html) 或 [报告模板](assets/report-template.html)，不带入旧行情。交付前运行 `scripts/check_report.py`；退出码2表示JS检查不完整，通过静态检查不替代浏览器验收。不能浏览器验收时说明限制。
