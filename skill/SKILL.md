# 油运行业研究

围绕用户的问题组织证据，不把历史案例的数字或判断自动填入新研究。本仓可独立使用；数据库、账号、浏览器或其他仓库均不是默认可用的依赖。

## 研究路径

用原油需求、有效运力、运距、地缘约束和浮舱五维清单定位资料缺口，区分原油船和成品油船。吨海里衡量运输需求，供给还受速度、往返、等待和船货适配影响；不要把老船年龄门槛、影子船队或绕航比例直接相加扣减。

沿供需、运价、公司盈利、估值逐层解释。航线评估、TCE、期租租金、FFA、公司实现值的单位和期间不同，先核船型、航线、成本口径与交割期限。TCE 不等于公司净利润，租入船仍可能有盈利弹性，取决于租约结构。

FFA 报价反映合约定价，不保证未来现货或股价；不能因一个历史案例写成稳定预测能力。PB 需保留净资产口径、日期和采样窗口，不能称唯一风险变量。历史类比是条件对照，单点反算不能验证普遍规律。

## 证据记录

每个关键数字记录：指标、值与单位、船型/航线/范围、观察期、发布/取得时间、来源链接或本地定位、原始发布者、转引链、证据状态及缺口。区分“原文已取得”“算术已复算”“来源未取得”“推导假设”，不得直接合并为已核实。

多家媒体转引同一个原始发布者，只算同一来源链。两家数据库结果接近，也不能自动证明上游数据独立。日频数据是否可用由声明的研究时点和交易日历决定，不能硬算五个自然日就是五个交易日。

已有资料可先形成限定判断；缺真实成交、参与航线、实际敞口或期间桥接时，不推算确定公司利润。缺成本或不同期限contango时，不宣称套利不可能。结论列出支持、反证、未知和何种新资料会改变判断。

## 独立核对与交付

- 复核期间、来源链、FFA误差、敞口或历史PB序列时，读取 [证据攻击检查](references/evidence-contracts.md)，运行 `scripts/evidence_checks.py`。阻断项保留为缺口；计算成功不认证来源、历史可得性或公司实际收益。不得使用单日验证月均、半年对全年、利润权重乘船数权重或把转载当独立证据。
- 需要算术核对时，读取 [方法与输入](references/calculation-contracts.md)，运行 `scripts/research_checks.py`。它只计算声明参数，不认证来源。
- 查数据字段时读取 [数据字典](references/data-dictionary.md)，取数前读取 [来源与权限](references/data-sources.md)。历史数值及工具名称不是当前事实或接口承诺。
- 复查旧观点时读取 [踩坑记录](references/pitfalls.md)。旧记录中的“已核清”或规律性语言需按本次证据重新判断。
- 按用户需求提供自然语言说明或 HTML；制作新报告使用 [空白仪表盘模板](assets/dashboard-template.html) 或 [报告模板](assets/report-template.html)，不复制旧报告填充默认行情。
- HTML 交付前运行 `scripts/check_report.py`。退出码2表示JS检查不完整；通过静态检查不等于浏览器验收或事实核实。浏览器无法使用时如实记录限制。

来源资料、付费数据和研报权利不随本仓MIT转移，不假定公开可读即允许批量采集或再分发。保留历史报告与输入，更新时另存版本。
