# 数据源清单与取数策略

## 一、金融数据库接口（可直取，最可靠）

以下为实测可用的接口与参数要点。数据口径统一、带时点，优先于任何搜索结果。

| 用途 | 接口 | 要点 |
|---|---|---|
| 分部收入构成 | `business_segments` | **分部拆解的首选**。一次可传多个代码，返回多期 product/region/sector 三个维度 + 同比。**只给收入，不给净利** |
| 行情与 K 线 | `quote_and_kline` | ⚠️ 请求区间交易日数超过 `limit` 时会插入"省略中间历史行情"记录，只返回最新 N-1 条 + 最早 1 条，**不适合拉完整序列做分布统计** |
| 估值与分位 | `valuation` | 返回 PE/PB 与 5 年分位，含 `history` 时序（可看动态 PE 变化）。**一次只能查一个代码** |
| 市值 | `market_cap` | 可多代码 |
| 利润表 / 资产负债表 / 现金流 | `income_statement` / `balance_sheet` / `cash_flow` | 支持多代码多报告期 |
| 财务指标 | `financial_indicators` | 毛利率、ROE 等 |
| 股东与基金持仓 | `shareholder` | **股价涨而基金减持**这类反直觉信号从这里出 |
| 南向持股 | `connect_holdings` | 港股通持股占比与变动 |
| 分红 | `dividend` | — |
| 技术指标 | `technical` | 筹码获利盘、乖离率 |
| 资金流 | `fund_flow` | — |
| 券商评级与预测 | `ratings` | ⚠️ **历史预测 12 次里 11 次高估**，用前先统计偏差 |
| 研报检索 | `report_search` | ⚠️ 对"船队艘数/载重吨"类查询**长期返回空**，不要依赖 |
| 宏观进口 | `macro_cn` | 中国进口量 |
| 汇率 | `forex` | AH 对比与美元换算需要 |
| 新闻 | `news` | 可按代码 + 日期区间过滤 |

**多代码参数格式**：`601872.SH,600026.SH,601975.SH`（英文逗号，无空格）。
**报告期格式**：`{财年}-{报告期}`，如 `2026-H1,2025-FY`。

## 二、联网搜索（转引为主，必标来源）

搜索效率最高的几类目标：

| 目标 | 有效关键词组合 | 命中率 |
|---|---|---|
| 官方弹性表 | 「中远海能 业绩推介PPT 运价弹性 每增加1万美元 TCE 边际收益」 | 高 |
| 船队逐船明细 | 「中远海能 分船型船队全表 半年报 载重吨 船龄」 | 高 |
| breakeven | 「中远海能 VLCC 保本点 盈亏平衡 TCE 折旧 财务成本」 | 中（多为自建模型转引） |
| 运价周报 | 「BDTI BCTI TD3C TD15 TD22 周均 TCE 月份」 | 高（券商周报） |
| 订单与交付 | 「VLCC 新船订单 在手订单占运力比 交付排期 克拉克森」 | 高 |
| 波罗的海日报 | 「Dirty Tanker Index Summary 日期」 | 高（一手点位） |
| 研究框架 | 「油运行业研究框架 吨海里 有效运力」 | 中（发现报告类站点） |

**搜索到的券商研报（国盛/国金/财通/长江/申万/华源）与业绩推介材料转引，质量明显优于数据库 `report_search`。**

## 三、一手源（最权威，优先于转引）

| 源 | 内容 | 获取 |
|---|---|---|
| **波罗的海交易所日报** | 各航线 WS/TCE、VLCC 综合 TCE、燃油价格、期租成交情况 | 经纪商站点转载，如 Optima Shipbroking 的 `Dirty Tanker Index Summary`，搜索「Dirty Tanker Index Summary + 日期」 |
| 克拉克森（Clarksons） | 船队/订单/拆解/船价全口径 | **付费**，只能通过券商研报或上海航运交易所报告转引 |
| 上海航运交易所 | 《水运形势报告》《国际油轮运输市场月度报告》 | **免费且引克拉克森数据**，是中文世界里最好的准一手源 |
| 海关总署 | 中国原油进口量 | 免费，数据库 `macro_cn` 亦可取 |
| 公司半年报 / 业绩推介 PPT | 船队逐船表、官方弹性表、分部数据 | 港交所披露易（HKEXnews）+ 公司官网 |

**上海航运交易所是被严重低估的源**——它引用克拉克森数据且免费公开，中文可读，实测提供了船队规模、交付量、订单量、拆解量、净增运力等一大批核心数据。

## 四、付费且取不到（只能间接引用）

- **克拉克森**全口径数据库：船队、订单、拆解、船价
- **Kpler / Vortexa**：AIS 船位追踪、浮舱数量、绕行比例
- **波罗的海交易所 / SSY** 原始 FFA 曲线
- **Clarksons Securities / Braemar** 客户报告

**处置：只能引用研报中的转引数字，必须在正文每处标注"非一手，需核原文"。**

## 五、判定不可信源的方法

遇到拿不出一手出处的聚合站（如 GEP Research 一类），**用一个已知数做交叉检验**：

| 检验项 | 该源声称 | 已知真值 | 判定 |
|---|---|---|---|
| 中国原油进口 | +4.1% | 海关 -11.4% | ❌ |
| 2026H1 拆解 | 47 艘 / 720 万 DWT | 克拉克森 24 艘 / 170 万 DWT | ❌ |
| 全球船队规模 | 5.2 亿 DWT | 克拉克森 6.78 亿 DWT | ❌ |

**任一项不通过 → 整体弃用，不要挑选性引用。**

## 六、取数顺序建议（实测高效的路径）

按此顺序可在 3–4 轮内把框架填满：

**第 1 轮（数据库，一次性批量）**
`quote_and_kline` → `income_statement` → `financial_indicators` → `market_cap` → `valuation`（逐个）→ `company_profile`

**第 2 轮（数据库补充层）**
`business_segments`（分部）→ `shareholder` → `cash_flow` → `dividend` → `ratings` → `connect_holdings` → `technical` → `fund_flow` → `macro_cn` → `forex`

**第 3 轮（搜索补缺口）**
运价周报 → 订单与交付排期 → 船队逐船明细 → breakeven → 官方弹性表 → 期租与 FFA

**第 4 轮（框架核查）**
搜"油运行业研究框架"对照自身框架缺什么 → 逐条复核关键数字 → 跑 `check_report.py`

**第 3、4 轮是最有价值的**——实测中框架补漏（浮舱囤油维度）与 TD3C 口径修正都来自这两轮，均推翻或修正了前两轮的结论。
