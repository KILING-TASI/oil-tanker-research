# 数据来源与权限

本仓没有内置联网采集器、数据库账号或金融工具连接器。旧案例中的business_segments、valuation等名称来自当时工具环境，不是本Skill提供的函数，也不保证当前可用。

## 按证据用途取资料

| 资料 | 原始入口 | 要核对 |
|---|---|---|
| 船队、租约、分部、现金流 | 公司官网、上交所披露、港交所披露易的原公告 | 报告期、合并范围、在营/在建、自有/租入、页码；管理层说法与财报字段分别记录 |
| 航线评估、TCE、FFA | [Baltic Exchange](https://www.balticexchange.com/en/data-services/market-information0/tankers-services.html) | 航线、船型、观察时间、评估/成交、结算期限、成本假设和访问许可 |
| WS基准 | [Worldscale](https://www.worldscale.co.uk/help) | 年度flat rate、港口组合、标准船、费率百分比及附加项 |
| 订单、交付、船龄、船价 | Clarksons等原统计报告或明确转引文件 | 单船型/全船队、DWT/艘数、现存/订单、日期、原统计者；没有账号就保留缺口 |
| 中国进口与贸易流 | 海关原统计发布 | 当月/累计、重量/金额、同比基期、修订版本 |
| 库存与原油曲线 | EIA原发布、获得授权的交易所/数据商 | 油种、地点、合约月份、发布日期、期限；不能拿13个月价差证伪3个月套利 |
| AIS、等待、STS | 合法授权的Kpler、Vortexa等记录 | 覆盖范围、识别规则、缺失船舶和服务权限；不能猜全市场 |
| 行情与PB序列 | 合法可得的交易所、公司披露与数据商 | 复权、股本、净资产版本、时点、采样窗口、缺失记录 |

## 来源状态

直接取得原发布者文件，才可标“原文已取得”；仍需核对具体页码、日期和字段。船舶经纪商/媒体转载Baltic内容属于转引，不能因为Baltic是原机构就标成直接一手取得。

不因发布者权威或不同网站给出同一数值，就省略上游链核查。两条链的原始发布者相同则不算独立证据；上游未知时，独立性也未知。

搜索结果摘要、媒体和券商报告可用于发现资料，但保留转引链与定位。一个数值与旧案例不同，先查日期、口径和修订，不能用固定50%差异阈值判整个来源不可信。

公开可读不自动等于允许抓取、批量下载或再分发；按来源许可使用，不绕过付费、登录和访问限制。无权限时记录缺口，不冒充已取得。
