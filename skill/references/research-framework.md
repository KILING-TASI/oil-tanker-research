# 油运研究：从行业机制到公司判断

本框架提供研究路径，不提供默认行情、船数、运价中枢或买卖规则。按用户问题选用相关层次。字段定义与来源入口分别见data-dictionary.md与data-sources.md。

## 1. 界定研究对象和时点

先明确原油/成品油、VLCC/Suezmax/Aframax或LR/MR、区域/航线、现货与远期窗口。公司比较另明确证券代码、财报期间和权益归属。混合船队按实际业务拆开，不由公司简称判断纯船型属性。

区分研究截止日、观察期、发布日期和取得日。事后取得的同一版本可用于事后复核，但不能自动证明原研究时点已有该资料。季度锁定收益、全年预测、已实现收益分别列示。

## 2. 需求：货从哪里来、走多远、用什么船

核产销与炼厂运行、出口/进口流向、原油和成品油贸易结构。石油消费增长可能由国内供给满足，不一定增加海运；某国进口下降不等于全球海运需求下降。

运输需求尽量用货量与运距的共同变化解释。核货源、目的地、船型和路线覆盖，区分吨海里、货量和同比百分比。地缘事件先确认事实，再查是否改变装卸港、绕航、贸易替代和运输距离；政策或媒体叙事不直接等于已发生运输增量。

需求判断列主要驱动、反向信号和未知覆盖；不将一项地区数据当全球需求裁决。

## 3. 供给：名义船队到可服务船日

分别记录在营船队存量、自有/租入/管理范围、在建订单、交付流量、拆解和退出。艘数与DWT不互换，订单占船数与占运力不混用。交付计划是预测，需订单版本、年份/区间、取消和延误边界；“2028+”不等于2028单年。

有效供给取决于航速、航次往返、港口等待、装卸、坞修、制裁和商业适配。年龄不是自动禁用门槛；受制裁、老船、影子船队和等待船可能是同一批船。无法去重时给范围或说明未知。

绕航既延长运输距离也占用船日。可以展示两种视角，但在一个需求/供给比值中不要将同一冲击完整算两遍。短期区域船位紧张不直接推出长期全球物理缺船。

浮舱是条件性占船需求：核同油种、地点和期限的价差，租船、资金、保险、损耗、装卸及船舶实际可得性；只有contango不够证明可执行套利。

## 4. 运价：识别价格结构和变化机制

| 观察对象 | 可说明 | 不能直接说明 |
|---|---|---|
| BDTI/BCTI指数 | 所覆盖市场的评估变化 | 单船收入或公司利润 |
| WS费率 | 年度航线基准下的运费比例 | 未换算的美元/日或统一保本线 |
| 航线评估TCE | 标准船与成本假设下的收益 | 公司实际参与、成交或实现收益 |
| 期租成交/指示价 | 对应船舶和期限的锁价条件 | 全市场预期或所有船日收益 |
| FFA报价 | 同航线合约窗口的远期定价 | 保证实现的现货、股价或盈利预测 |
| 公司实现/已锁定TCE | 对应船队和已披露船日表现 | 未覆盖船日、其他公司或完整未来季度 |

结合货盘、可用船位、成交与评估方法解释上涨/下降。不同区域或船型分化时保留分化，不压成一个“油运整体价”。一周无新成交还需覆盖和询盘证据，不能直接推断租家看跌。

检查公司已锁定收益覆盖率、统计船日与压载影响。不能把已锁定部分按覆盖率简单除算完整季度TCE；需要剩余部分的同定义收益与天数。未来实现值未知时只给条件情景。

## 5. 公司：逐层解释收益如何兑现

把市场航线映射到公司实际经营的船型、航线、权益和盈利船日，再核现货、期租、COA、POOL、租入成本和分成。没有映射证据时只判断行业暴露方向。

TCE增量的机械桥接可从适用船日、现货敞口、汇率等开始，但航次成本、经营成本、折旧、融资、税费、其他业务和少数股东权益须分别说明。分部利润可能不是归母；不得直接用分部净利占合并归母当利润权重。

敏感性只描述基准附近的边际变化。由利润反推TCE须有同口径基准利润和基准运价，不能把敏感性当经过原点的利润函数。跨极端运价区间、换船队规模或租约结构后不能默认系数不变。

现金保本核是否包含经营费、租船、坞修、融资或偿债等具体项目；会计保本还涉及折旧、税费与分部范围。国外船东现金指引不能认证国内船东会计保本。

核利润质量、经营现金与应收、资产出售和汇兑等非重复因素。资本开支区分已支付、合同承诺和新订单；半年支付年化不证明全年投资翻倍。股利方案、批准、实施、除息和支付状态分别记录，回购与分红不混称现金派息。

## 6. 估值：判断的对象和适用范围

按可得资料选择正常化利润/现金流与NAV交叉观察。NAV需要船型船龄、可比成交、资产权益、债务/租赁、现金、在建承诺等范围；不把新船价直接套所有旧船。不同方法使用一致的股本和权益口径，避免同一负债重复扣除。

PB核当前价格、账面净资产、采样窗口和历史修订；PE核已实现/预测、异常收益与周期位置。高PB分位是样本位置，不是必跌概率；低PE不自动便宜或自动陷阱。

短期峰值利润不默认永续。高运价既可能改善现金也可能推动昂贵扩船，分开评估。没有完整盈利桥接时不给确定目标价或精确安全边际。

## 7. 情景和结论

选择与问题有关的情景，例如航线恢复、需求回落、船舶周转改善、交付延后/增加、燃油保险变化或高价延续。每个情景列外生假设、受影响船型/航线、公司映射、测算范围及失效条件；无概率依据时不算期望收益。

同一因素可以作用于多个层次，但检查重复计量。历史类比先匹配驱动、船队结构、计价和政策条件，不由一个相似图形建立必然回撤规律。

可交付的结论例如：“披露支持已报告期间某业务盈利改善；是否持续取决于船日锁定与有效运力变化；当前缺租约和远期原始曲线，因此不能量化全年利润。”明确说明证据支持到哪一步，也回答当前最合理的方向判断。

## 8. 用独立事实支撑复合结论

一个事实的身份由指标、主体/范围、期间、单位、定义和来源版本共同确定。相同事实在正文/表格/图中复用编号，数值相同但船型或时期不同不能合并。

例如用户问“高运价是否说明公司便宜”，先登记：F1同窗口航线评估、F2公司已披露船日/租约、F3公司实际利润、F4估值输入。计算C1引用F1/F2并标注尚缺参数；结论J1引用F3/F4/C1，并明确从市场到公司、从短期到正常化之间还缺什么。

F1支持不代表F2成立；C1算式正确不代表F1真实；J1中某一环未知，不应把已取得的F3也重置为未完成。分别显示事实来源状态、计算口径状态和推断支持程度。来源说明、标题及免责声明作为元信息，不与待取证事实一起统计。
