# 油运研究数据字典（四层传导链）

每层列出：必取数据 → 口径要点 → 来源 → 可得性。可得性标记：**【库】**金融数据库接口可直接取；**【搜】**需联网检索（多为转引）；**【付费】**取不到，只能间接引用。

实测对照（2026-10-06，波罗的海）：TD3C 134.70 万 / TD15 72.22 万 / TD22 49.87 万 / TD34 89.53 万 / **VLCC 综合 85.60 万**。**TD3C 是 TD22 的 2.7 倍。**

### WS（Worldscale）换算

- WS 100 = 7.5 万吨级油轮在最经济运营条件下的盈亏平衡运费
- TD3C 换算示例：WS 140 × 18.63（基准费率）× 270,000 吨 → 日租金约 17.6 万美元
- 极端行情下（如海峡受阻）TD3C 参考价值受限，需结合替代航线与实际成交

## 第三层：公司盈利

| 数据 | 口径要点 | 来源 | 可得性 |
|---|---|---|---|
| **分部收入构成** | **最优数据源，一次可取多公司多期 + 同比**。中远海能可拆到外贸原油/外贸成品油/内贸原油/内贸成品油/LNG/化学品/LPG | `business_segments` 接口 | 【库】✅ 首选 |
| 分部净利 | 数据库通常只有收入，**净利需从券商研报或半年报取** | 券商点评、半年报 | 【搜】 |
| 分船型船队明细 | 艘数、载重吨、自有 vs 租入、船龄、在建。中远海能业绩推介 PPT 有逐船表 | 半年报、业绩推介 PPT | 【搜】 |
| 租船结构 | **现货敞口 vs 长协（COA/期租/POOL）决定弹性分化** | 业绩会、投资者关系记录 | 【搜】 |
| **breakeven TCE** | **回答"跌到多少利润归零"的必需项**。中国口径约 2.4 万美元/天 = 折旧 1.01 + 财务 0.7 + 运营 0.7（假设 9,600 万美元/艘、22 年折旧、70% 负债、4% 利率）。对照 Frontline 国际口径 2.38 万，差 1.3% | 公司交流纪要、自建模型 | 【搜】⚠️ 多为转引 |
| **分船型弹性表** | **每 +1 万美元/天 TCE 的年化边际收益**。中远海能官方表：VLCC 9.34、阿芙拉 2.72、LR1 2.50、LR2 1.49、灵便黑 0.78、灵便白 1.12，**全外贸油轮合计 17.95 亿** | 业绩推介 PPT | 【搜】⚠️ 转引 |
| 全公司弹性 | 招商轮船 12.11 亿（国金）/ 11 亿（券商框架）；中远海能 9.5 亿（VLCC） | 券商研报 | 【搜】⚠️ 口径坑 |
| 营业成本增速 | **经营杠杆的直接量化**：营收 +56.15% 而营业成本仅 +12.38% | 财务三表 | 【库】 |
| 经营现金流 / capex | capex 在周期顶点加速 = 风险。2026H1 中远海能 capex 已超 2025 全年 | 现金流表 | 【库】 |
| 分红与支付率 | 招商轮船 2025 年支付率 43%，2026 中期 15.08% | 分红接口 | 【库】 |
| 运量 vs 周转量 | **量价背离的关键证据**：招商轮船 VLCC 运量 -8.9%，利润 +378% | 半年报 | 【搜】 |

### 弹性测算的三条路径（必须互相验证）

1. **船队规模法**：艘数 × 365 天 × 1 万美元 × 汇率 × (1-税率)。51 艘 VLCC → 税前 13.2 亿，税后 9.9–11.2 亿
2. **业绩反推法**：本期净利增量 ÷ 同期 TCE 价差。招商轮船 H1 增量 48.96 亿 ÷ 6.55 万 ≈ 7.5 亿/半年 → 年化 15 亿
3. **官方弹性表法**：直接用业绩推介 PPT 的分船型表

三条路径应落在同一量级（偏差 <25%）。**若不吻合，说明口径不一致，必须先解决再往下算。**

用模型反推隐含运价的正确做法：

```
隐含 TCE = breakeven + (目标净利 − 其他板块贡献) ÷ 弹性
```

**不能直接"净利 ÷ 弹性"**——不扣保本点、不扣其他板块会系统性高估。
